# Contribuindo

Obrigado pelo interesse no projeto.

## Fluxo sugerido

1. Faça um fork do repositório.
2. Crie uma branch para sua alteração:

```bash
git checkout -b feature/minha-alteracao
```

3. Faça a alteração.
4. Teste localmente.
5. Faça o commit:

```bash
git add .
git commit -m "feat: descreve a alteração"
```

6. Envie a branch:

```bash
git push origin feature/minha-alteracao
```

7. Abra um Pull Request.

## Padrão de commits

Quando possível, utilize mensagens simples e descritivas:

- `feat:` nova funcionalidade
- `fix:` correção
- `docs:` documentação
- `refactor:` refatoração
- `chore:` manutenção

## Pull Requests

Descreva:

- o que foi alterado;
- por que a alteração foi necessária;
- como testar;
- possíveis impactos.
